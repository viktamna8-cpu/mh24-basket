MH24 BASKET — FREE DEPLOY STEPS (Marathi + English)
=====================================================

तुम्हाला 2 फुकट (Free) accounts लागतील:
1) GitHub account   -> github.com
2) Vercel account   -> vercel.com

एकूण वेळ: 10-15 मिनिटे. काहीही खर्च नाही.


STEP 1 — GitHub Account बनवा
-----------------------------
1. github.com वर जा
2. "Sign up" दाबा
3. Email + Password टाकून account तयार करा


STEP 2 — नवीन Repository बनवा
-------------------------------
1. GitHub मध्ये लॉगिन झाल्यावर, वरती उजवीकडे "+" आयकॉन दाबा
2. "New repository" निवडा
3. Repository name: mh24-basket
4. Public निवडा
5. "Create repository" दाबा


STEP 3 — पूर्ण फोल्डर अपलोड करा
---------------------------------
1. तुम्हाला दिलेला संपूर्ण "mh24-basket" फोल्डर unzip करा (जर zip असेल तर)
2. GitHub repository पेजवर "uploading an existing file" या लिंकवर क्लिक करा
3. फोल्डरमधल्या सगळ्या फाईल्स आणि सबफोल्डर्स (src, public, package.json,
   vite.config.js, index.html, इ.) एकत्र drag करून टाका
   (टीप: फाईल upload करताना फोल्डर स्ट्रक्चर तसाच राहील याची खात्री करा —
   जर GitHub वेबसाईटवरून drag-drop त्रासदायक वाटलं, तर खाली दिलेली
   "GitHub Desktop पद्धत" वापरा — ती सोपी आहे)
4. खाली स्क्रोल करून "Commit changes" दाबा


STEP 3 (सोपा पर्याय) — GitHub Desktop वापरून अपलोड
-----------------------------------------------------
1. desktop.github.com वरून GitHub Desktop डाउनलोड आणि इन्स्टॉल करा
2. उघडून तुमच्या GitHub account ने लॉगिन करा
3. "Add" -> "Add Existing Repository" -> तुमचा mh24-basket फोल्डर निवडा
   (जर ते "not a git repository" म्हणत असेल, तर "create a repository" पर्याय
   दाबा)
4. खाली डावीकडे "Publish repository" बटण दाबा
5. सगळ्या फाईल्स आपोआप GitHub वर जातील


STEP 4 — Vercel Account बनवा
------------------------------
1. vercel.com वर जा
2. "Sign Up" दाबा
3. "Continue with GitHub" निवडा (सगळ्यात सोपं)
4. GitHub ला परवानगी द्या (Authorize Vercel)


STEP 5 — Project Import आणि Deploy करा
-----------------------------------------
1. Vercel Dashboard वर "Add New..." -> "Project" दाबा
2. तुमचा "mh24-basket" repository शोधून "Import" दाबा
3. Framework Preset आपोआप "Vite" दाखवेल — काही बदलायची गरज नाही
4. "Deploy" बटण दाबा
5. 1-2 मिनिटांत तुमचं app तयार होईल आणि तुम्हाला एक लिंक मिळेल, उदा:
   https://mh24-basket.vercel.app


STEP 6 — लिंक शेअर करा
-------------------------
- ही लिंक कुठल्याही ग्राहकाला WhatsApp/SMS वर पाठवा
- ग्राहक फक्त लिंकवर क्लिक करून browser मध्ये app उघडू शकतो
- कुठलीही installation लागत नाही (हे PWA सारखं काम करतं)
- ग्राहक "Add to Home Screen" करून हे मोबाईलवर app सारखं ठेवू शकतो
  (Chrome मध्ये: ⋮ मेनू -> "Add to Home screen")


IMPORTANT NOTES
-----------------
- WhatsApp नंबर बदलायचा असेल तर: src/App.jsx मध्ये
  WHATSAPP_NUMBER शोधा आणि नंबर बदला (91 + 10 digit number, कुठलेही + किंवा
  स्पेस शिवाय)

- Admin password बदलायचा असेल तर: src/App.jsx मध्ये
  ADMIN_PASSWORD शोधा आणि नवीन password टाका

- कुठलाही बदल केल्यावर, GitHub Desktop मध्ये पुन्हा "Commit" आणि "Push"
  करा — Vercel आपोआप नवीन version deploy करेल (काही सेकंदात)

- हे पूर्णपणे मोफत आहे. Vercel च्या free plan मध्ये लहान/मध्यम व्यवसायासाठी
  पुरेसे traffic limits आहेत.
